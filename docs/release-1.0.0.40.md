## 简体中文

- 新增只读 `get_dev_plugin_state`：按准确 DLL 路径查询开发插件注册、生命周期、实际自动重载开关，以及文件和运行程序集的 MVID。新增只读 `wait_for_dev_plugin`：锁定目标构建，等待运行 MVID 一致并持续加载 750ms；不扫描、不调用加载、不保存配置、不修改开关，变更权限关闭时仍可使用。超时明确返回 `buildVerified=false`，再次构建造成有效 MVID 改变时拒绝继续确认。
- 优化 `load_dev_plugin`：省略 `autoReload` 保留已有设置，仅新注册默认开启。已加载或处于加载／卸载过渡的自动重载插件走验证路径，不重复扫描、保存或调用 `LoadAsync`；真正未加载的插件仍可按请求加载。技能、服务器初始化说明和项目文档统一要求：自动重载已开启时使用只读等待工具，验证成功后再测试插件。
- 验证：Debug / Release 构建均 0 警告、0 错误；开发插件回归 50 项、程序集身份检查 3 项、Release 插件加载测试 213 项、协议测试 60 项通过。覆盖已有关闭设置保留、显式开关变更、新注册、旧构建、实例替换、卸载过渡、DLL 写入中、超时、线程调度停滞和权限限制。实际游戏中 12 项只读断言通过，完整目录为 162 项；运行构建 MVID 与测试 Debug DLL 一致，开关和注册状态保持不变，未调用 `load_dev_plugin`，未使用游戏输入。
- 限制：关闭自动重载的旧运行构建不会被等待工具自动加载或改动设置，需要有授权的生命周期操作。MCP 宿主自身重载会断开正在等待的请求，需要重连并核对 `/health.buildMvid`。实际游戏验证覆盖宿主的只读查询／等待和未注册 DLL 的超时；加载工具各变更分支及关闭权限场景由离线夹具验证，未现场切换全局权限或其他插件开关。

## English

- Adds read-only `get_dev_plugin_state` for exact DLL-path inspection of developer registration, lifecycle, actual auto-reload setting, and file/loaded assembly MVIDs. Adds read-only `wait_for_dev_plugin`, which pins the target build and requires its running MVID to match and remain loaded for 750ms. It never scans, loads, saves configuration or changes the watcher, and remains available with mutation access disabled. Timeout explicitly returns `buildVerified=false`; a different valid MVID from another build is refused.
- Improves `load_dev_plugin`: omitted `autoReload` preserves existing settings; only new registrations default to enabled. An auto-reloading plugin already loaded or transitioning through loading/unloading takes the verification path without another scan, save or `LoadAsync`; an unloaded plugin can still receive its requested initial load. Skills, server initialization instructions and project documentation consistently route enabled auto-reload to the read-only wait tool before plugin testing.
- Validation: Debug / Release builds completed with zero warnings/errors. All 50 developer-plugin regressions, 3 assembly-identity checks, 213 Release plugin-load checks and 60 protocol checks passed. Coverage includes preserving disabled settings, explicit watcher changes, new registration, stale builds, replacement instances, unload transitions, partial DLL writes, timeout, stalled framework scheduling and permission gates. All 12 read-only live assertions passed, with 162 tools in the complete catalog. The running build MVID matched the tested Debug DLL, watcher/registration state remained unchanged, and no `load_dev_plugin` or gameplay input was dispatched.
- Limitations: waiting does not load an obsolete build whose watcher is disabled or change its settings; an authorized lifecycle action is required. Reloading the MCP host disconnects pending waits: reconnect and verify `/health.buildMvid`. Live coverage includes host read-only inspection/readiness and unregistered-DLL timeout. Mutating loader branches and closed-gate scenarios have offline fixture coverage; global permissions and other plugins' watcher settings were not changed in game.
