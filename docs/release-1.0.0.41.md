- 同步器校验全部包与文件指纹，自动迁移 40 个已知历史原版，升级未修改的受管副本并保留其他文件。拒绝覆盖本地修改／删除、未知或较新受管版本、新文件冲突、符号链接／junction 和本仓库维护源码；不改 `AGENTS.md`、MCP／客户端配置或权限。重复同步不写文件，普通写入失败会尝试恢复此前替换。客户端权限与用户策略始终优先。
- Release 增加长期技能 ZIP、清单和离线同步 payload；CI 技能产物保留 30 天。修正安装副本的仓库外相对文档链接，技能、接入指南、打包工具和后续发布流程同步更新。
- 验证：Debug／Release 构建均 0 警告、0 错误；21 项指引目录检查、23 项 Python 同步测试（包含全部 40 个历史修订迁移）、215 项 Release 插件加载检查及 62 项协议检查通过；Skill 校验及 81 个相对链接检查通过。18 项实际 MCP 端到端断言通过：运行 MVID 匹配测试 DLL，工具完整目录为 163 项，服务端技能包与发布包字节一致；隔离客户端的 1.0.0.40 原版自动更新、新安装、重复无写入、本地修改保留和会话回退均验证。未修改真实用户的 Skill 或全局变更权限，未使用游戏输入。

## English

- Adds read-only `get_agent_guidance` for the running build's bundled skill revision, SHA-256 manifest, ZIP, client updater and individual guidance files. MCP initialization proactively guides the agent to install/synchronize its active skill, independently of old skill instructions or GitHub connectivity. Successful routine updates stay quiet; the agent reads the updated guidance and continues the original task. `/health.agentGuidance` and settings show the recommended revision while explicitly marking client installation status unknown.
- The updater verifies package/file fingerprints, migrates all 40 recognized pristine historical revisions, upgrades unchanged managed copies and preserves unrelated files. It refuses to overwrite local edits/deletions, unknown/newer managed revisions, new-file collisions, symlinks/junctions and this repository's authoring source. It changes no `AGENTS.md`, MCP/client configuration or permissions. Repeated synchronization makes no writes; ordinary write failures attempt to restore earlier replacements. Client permissions and user policy remain authoritative.
- Releases now include durable skill ZIP, manifest and offline synchronization payload assets; CI guidance artifacts have 30-day retention. Fixes repository-relative documentation links in installed copies and updates the skill, onboarding, packaging and future release procedure.
- Validation: Debug/Release builds completed with zero warnings/errors. All 21 guidance catalog checks, 23 Python sync tests (including migration of every one of the 40 historical revisions), 215 Release plugin-load checks and 62 protocol checks passed, as did skill validation and 81 relative-link checks. All 18 real MCP end-to-end assertions passed: running MVID matched the tested DLL, the complete catalog contained 163 tools, and served/release guidance packages were byte-identical. Isolated-client upgrade from pristine 1.0.0.40, fresh installation, no-write repetition, preservation of local edits and session-only fallback were verified. No real user's skill or global mutation permission was changed; no gameplay input was used.
- Limitations: automatic synchronization depends on an agent following initialization guidance and having local filesystem/Python execution access. Connecting grants no extra permissions; behavior cannot be guaranteed across third-party models/clients. Missing capabilities or conflicts preserve the copy, produce one actionable report and allow matching session-only guidance; client caches may still need refresh. Independent-model instruction-following has not been evaluated. Replacements are atomic per file, not crash-atomic across a directory under process termination or concurrent editing. Closed game-mutation-gate reads have offline load-test coverage; settings text was build-validated without pixel-level appearance testing.

Details: [agent skill synchronization](https://github.com/NiGuangOwO/DalamudMCP/blob/v1.0.0.41/docs/agent-guidance.md); [live verification](https://github.com/NiGuangOwO/DalamudMCP/blob/v1.0.0.41/research/agent-guidance-sync-2026-11-01/live-verification.json).
