## 简体中文

- 新增三项地图只读工具：`convert_map_coordinates` 使用明确的 Map 行及当前 SDK 转换世界、地图显示与 2048 纹理坐标；`get_map_flags` 读取有界原生旗标；`find_nearest_aetheryte` 按同区域世界 X/Z 平面距离排序。位置优先使用 Level，缺失时只接受唯一的地图标记匹配，包括 Map 字段为零的城市碎片。高度、楼层、城市碎片解锁状态无法确定时保持未知；不打开地图、设置旗标、刷新传送列表或传送。
- 新增只读 `get_character_tethers`，读取原生角色连线槽，并可扫描加载对象的传入连接。保留稀疏槽位、完整 64 位对象 ID、原始进度字节及未解析目标；最多扫描 2048 个对象槽位、返回 100 条连接，报告覆盖不足和截断。不安装钩子。
- 新增只读 `get_item_stat_breakdown`，区分未镶嵌物品模板和带确切品质编码 ID 的实际随身包/装备/兵装库槽位。分列基础、HQ、全部五个魔晶石槽、部位/职能修正后的上限、有效值与溢出。上限按远离零的中点舍入；缺失的魔晶石或上限不会生成貌似完整的合计。
- 同步工具参考、服务器指引、Skill 和 CI，未新增 ECommons 运行时依赖。参数与边界见[地图、连线与装备只读查询](https://github.com/NiGuangOwO/DalamudMCP/blob/v1.0.0.59/docs/read-only-state.md)。五项工具均不需要变更权限。

验证：本地 Debug、Release 构建均通过，无警告或错误。新增隔离测试使用国服 SDK 完成 60 项检查（含真实游戏数据），国际服 SDK 完成 52 项结构/数学检查，覆盖保护页、未知值、稀疏连线/魔晶石、64 位 ID、HQ 加成、上限舍入、职能修正和溢出。插件加载/真实 HTTP 集成 279 项、协议 89 项、原生 UI 回归 268 项、C# 指引 22 项、Python Skill 同步 23 项、发布流程 14 项检查通过。国服完成 24 项只读现场检查，核对自动重载后的 MVID、201 项工具目录和 Skill 修订；验证坐标往返、利姆萨四个水晶/碎片的排序与解锁筛选、实际 NQ 装备和带五颗魔晶石的 HQ 兵装库物品，以及错误物品 ID 的拒绝。现场旗标为空，连线扫描覆盖 819 个对象槽位、155 个角色，结果完整且为空。本批未派发游戏输入或安装观察钩子，临时运行时引用已释放。

限制：现场没有非空旗标或连线，正例和边界仅在隔离内存验证；国际服未做游戏内验证。缺失或歧义的水晶位置保持未知，平面距离不证明路径、可达性或费用，未知高度不能用作移动目的地。连线是当前快照，不是机制历史。装备结果是未同步的物品与普通魔晶石属性，不应用等级/品级同步、古武自定义分配、特殊/套装效果、耐久影响、食物、药品或职业特性，不等于角色面板。

## English

- Added three read-only map tools: `convert_map_coordinates` uses an explicit Map row and the installed SDK to convert world, map-display and 2048 texture coordinates; `get_map_flags` reads bounded native flags; `find_nearest_aetheryte` ranks same-territory destinations by planar world X/Z distance. Locations prefer Level data and otherwise require a unique map-marker match, including city shards whose Map field is zero. Unknown height, floor and individual shard unlocks remain unknown. These queries do not open maps, set flags, refresh teleport lists or teleport.
- Added read-only `get_character_tethers` for native character slots and optional incoming-link scans across loaded objects. Sparse slots, full 64-bit object IDs, raw progress bytes and unresolved targets are preserved. Scans are bounded to 2048 object slots and 100 returned edges, with incomplete coverage and truncation reported. No hooks are installed.
- Added read-only `get_item_stat_breakdown`, distinguishing unmelded templates from exact quality-encoded items in physical carried, equipped or armoury slots. It separates base, HQ, all five materia slots, role/slot-adjusted caps, effective values and overflow. Caps use midpoint rounding away from zero. Missing materia or cap inputs cannot produce a seemingly complete total.
- Updated tool references, server guidance, the skill and CI without adding an ECommons runtime dependency. See [read-only map, tether and equipment queries](https://github.com/NiGuangOwO/DalamudMCP/blob/v1.0.0.59/docs/read-only-state.md) for arguments and limits. All five tools remain available without mutation access.

Validation: Local Debug and Release builds passed without warnings or errors. New isolated tests passed 60 checks against the CN SDK, including real game data, and 52 layout/math checks against the Global SDK. Coverage includes protected pages, unknown values, sparse tethers/materia, 64-bit IDs, HQ contributions, cap rounding, role modifiers and overflow. Plugin loading/real HTTP integration passed 279 checks; protocol 89; native UI regressions 268; C# guidance 22; Python skill synchronization 23; and release pipeline 14. Twenty-four read-only live CN checks verified the auto-reloaded MVID, 201-tool catalog and skill revision, coordinate round trips, four Limsa crystal/shard locations and unlock filtering, actual NQ equipment, an HQ armoury item with five materia, and expected-item mismatch refusal. Live flags were empty. The complete tether scan covered 819 object slots and 155 characters and found no connections. This batch dispatched no game input and installed no observers; temporary runtime references were released.

Limitations: Nonempty flags and tethers were unavailable live; positive and boundary cases were verified only in isolated memory. Global was not tested in game. Missing or ambiguous crystal locations stay unknown. Planar distance does not establish a route, reachability or cost, and unknown height is not a movement destination. Tethers are current snapshots, not mechanic history. Equipment results are unsynced item and normal-materia components. Level/item-level sync, relic allocations, special/set bonuses, durability effects, food, medicine and job traits are not applied; these results are not the active character panel.
