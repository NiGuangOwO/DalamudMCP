## 简体中文

- 新增 `list_dev_plugins`，分页查看安装器中的开发插件及明确配置的绝对 DLL 路径，包含缺失 DLL、实际加载状态、启动加载／自动重载／错误通知设置和路径启用状态。同名的不同构建按 DLL 路径区分；目录及相对路径只计数，不主动扫描。
- 新增 `set_dev_plugin_settings`、`unload_dev_plugin` 和 `remove_dev_plugin`，分别修改指定设置、卸载并验证状态、卸载和释放实例后移除单个 DLL 注册。操作保留本地 DLL、清单及插件配置，拒绝管理 MCP 自身、歧义目标和正在切换的插件。卸载／移除超时不取消已启动的 Dalamud 任务；底层任务结束前继续阻止重复开发插件操作。
- 新增 `disable_repository_plugin`，按准确在线插件名称和版本修改该插件在所属配置中的启用状态，卸载并验证在线实例，保留在线安装和配置。Skill 与服务指引规定：加载本地版前，先禁用同名在线版，轮询至验证成功并确认已卸载，再加载本地 DLL 并核对 MVID。加载器允许已禁用且已卸载的同名在线版保留安装，同时拒绝仍启用或被配置要求加载的在线版。
- 验证：Debug／Release 构建零警告、零错误；113 项开发插件、60 项安装器、254 项插件加载、89 项协议、22 项 Skill 目录、23 项 Skill 同步及 13 项发布流程检查通过。国服运行中的本地 Debug 构建验证了全部 189 个工具目录，并用临时在线／本地插件完成先禁用在线版再加载本地版、设置、卸载、重新加载、正常与缺失 DLL 注册移除及保留文件检查。临时注册、测试配置、在线安装和仓库已清理，原有 23 条开发插件状态与设置保持一致。
- 限制：不移除目录注册；默认开发目录中保留的文件可能在日后扫描时重新出现。启用的文件监听器可能在卸载后因新构建而再次加载插件。`saveQueued` 代表 Dalamud 接受保存请求，不等于已独立核验落盘；配置覆盖仍要求启用在线插件时会报验证失败，已完成的配置修改不会自动回滚。实机验证仅覆盖本地国服 Debug 构建及临时测试插件，未验证所有第三方插件、国际服或发布包在游戏中的行为。

## English

- Added `list_dev_plugins` to page developer instances and explicit absolute DLL locations from the installer, including missing DLLs, actual lifecycle state, startup/auto-reload/error-notification flags and location enablement. Different builds sharing an internal name are identified by DLL path. Directory and relative locations are counted without scanning them.
- Added `set_dev_plugin_settings`, `unload_dev_plugin` and `remove_dev_plugin` to change supplied flags, unload and verify state, or unload/dispose an instance and remove one explicit DLL registration. Local DLLs, manifests and plugin configuration are preserved. The MCP host, ambiguous targets and transitioning plugins are protected. Unload/removal timeouts do not cancel started Dalamud tasks; duplicate developer operations remain blocked until the underlying task ends.
- Added `disable_repository_plugin` to change the exact online name/version's preference in its declaring profiles, unload it and verify the online instance while retaining its installation and configuration. Skill and server guidance require disabling a same-name online copy, polling to verified success and confirming unload before loading the local DLL and checking its MVID. The loader permits a disabled, unloaded online copy to remain installed and refuses an online instance that is still enabled or wanted by an active profile.
- Validation: Debug/Release builds have zero warnings and errors; 113 developer-plugin, 60 installer, 254 plugin-load, 89 protocol, 22 skill-catalog, 23 skill-sync and 13 release-pipeline checks passed. A running local CN Debug build exposed the complete 189-tool catalog. Temporary online/local fixtures verified disabling the online copy before local loading, settings, unloading, loading again, normal and missing-DLL registration removal, and file preservation. Temporary registrations, test settings, online installation and repository were cleaned up; the original 23 developer entries retained their states and settings.
- Limitations: folder registrations are not removed, and files left in the default developer directory can reappear after a later scan. An enabled watcher can reload an unloaded plugin after a new build. `saveQueued` acknowledges Dalamud's save request, not independently verified disk persistence. A profile override still requesting the online plugin causes verification failure, and completed preference changes are not automatically rolled back. Live checks cover only local CN Debug builds and temporary fixtures, not every third-party plugin, the global client or the published package running in game.
