- 四个固定 HTTPS GET 在游戏线程外并行运行，10 秒总期限；元数据每项最多 1 MiB，源码 ZIP 最多 2 MiB、4096 个归档条目、512 个目录文件，单文件 1 MiB、目录解压总计 8 MiB。只在内存读取归档，不落盘解压或执行，不使用用户凭据，不接受自定义 URL 或重定向。源码检查不依赖 GitHub API 配额。
- 成功结果缓存 5 分钟，部分／失败结果 30 秒；`force=true` 可跳过缓存，并发检查拒绝重复发起。按来源保留错误；未知比较返回 null，不误报“已是最新”。不要求登录或开启变更权限，不启动定时后台任务，不修改抓包、opcode 表或当前包体定义。

## English

- Adds read-only `network_packet_schema_check_updates` for on-demand checks of both elpis npm `latest` versions and SHA-512, GitHub packet-structure directory content, and opcode-worker alias/direction catalog SHA-256. New releases, same-version artifact changes and possibly unpublished reference changes are reported separately.
- Four fixed HTTPS GETs run in parallel off the game thread with a 10-second total deadline. Limits: 1 MiB per metadata response; source ZIP 2 MiB, 4096 archive entries, 512 directory files, 1 MiB per file and 8 MiB uncompressed directory content. Archives are read only in memory, never extracted or executed. No user credentials, custom URLs or redirects. Source checking does not depend on GitHub API quota.
- Success results cache 5 minutes, partial/failed results 30 seconds. `force=true` bypasses the cache; concurrent checks are refused. Per-source errors remain explicit; unknown comparisons are null, not “up to date.” No login/mutation access, scheduled polling, capture changes, opcode refresh or definition replacement occurs.
- Validation: Debug / Release builds completed with zero warnings/errors; 385 network checks, 209 Release plugin-load checks and 59 protocol checks passed. Coverage includes version ordering, cache, rate-limit/HTTP errors, redirects, response/archive budgets, corrupt/duplicate/unsafe archive paths, deadlines, concurrency and unload cancellation. Schema regeneration produced the same hash. The running MVID matched the Debug DLL, and all catalog pages totaled 160 tools. Fourteen live assertions passed: all four real upstream checks completed, cache hit, and schema hash, opcode catalog, capture and hook state remained unchanged. No gameplay input or new capture was used.
- The observed latest versions were 0.1.0 for both packages, with no detected structure-directory or alias-catalog change. Results describe upstream state at check time, not protocol compatibility. The separately reviewed source baseline is not asserted to be the npm release commit. Content comparison excludes archive roots, timestamps and unrelated files; bounded ASCII paths, network/deadline/budget limits may yield unknown results. Only npm `latest` is checked, not every prerelease channel. Applying changes still requires review, importer pin updates, regeneration, validation and a plugin release. Existing ActionRequest 32 / 40-byte differences and seven unmapped schemas are not fixed by update checking.

Details: [packet schemas and online checks](https://github.com/NiGuangOwO/DalamudMCP/blob/v1.0.0.38/docs/packet-schemas.md); [live verification](https://github.com/NiGuangOwO/DalamudMCP/blob/v1.0.0.38/research/network-schema-updates-2026-11-01/live-verification.json).
