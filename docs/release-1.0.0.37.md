## 简体中文

- 新增只读 `network_packet_schema`，查询固定 elpis 包体结构、字段、枚举、来源和名称别名；`network_capture_status` 同时报告 schema 目录信息。
- 新增只读 `network_capture_parse`，按捕获时固定的 opcode 名称、FFXIVOpcodes 别名与收发方向自动选择结构，自动跳过发送 32 / 接收 16 字节头。支持嵌套对象、固定数组、整数、浮点、UTF-8、bytes、bitset、枚举及定点显示值；支持字段分页、明确的缺失/截断状态与同方向手动选型。保留原有手写字段解析工具。
- 随插件打包 `elpis-network` / `elpis-struct` 0.1.0 的静态元数据：177 项包结构、218 个可达结构，其中 170 项有方向/名称目录元数据（157 接收、13 发送）。7 个 Fellowship 结构缺少该元数据，仅供查询。导入脚本校验固定 npm SHA-512 和目录 SHA-256；插件运行时不执行 JavaScript、不依赖 Node、不联网加载 schema。GPL / AGPL 与 FFXIVClientStructs MIT 来源声明随 ZIP 分发，生成器和 JSON 随源码公开。
- 验证：Debug / Release 构建均 0 警告、0 错误；网络测试 333 项、Release 插件加载测试 207 项、协议测试 59 项通过。固定快照再生成 SHA-256 一致。真实游戏中验证加载 MVID 与测试 DLL 一致，工具目录完整分页为 159 项；10 秒被动观察捕获 80 包（发送 5、接收 75），11 类结构匹配，1431 个可用字段与独立 Python 解码一致，3091 项现场断言通过。没有发送游戏输入或注入网络包，结束后两个 hook 均关闭。
- 实际限制：样本中 65 包按布局读取完成；4 个 ActionRequest 实际包体 32 字节，小于 schema 的 40 字节，明确返回 `short_payload`，缺失尾部字段不补零。9 包无 opcode 名称，2 包无结构。导入数量不代表现行国服完整适配，长度/名称匹配不认证字段语义或补丁兼容。条件显示/条目有效性规则仅保留元数据，EXD 引用不自动查名字。捕获仍限已检查的国服进程内区域 IPC；高负载/全部包类型与其他地区未全面验证。非完整协议、TCP/PCAP 或服务端送达确认。

## English

- Adds read-only `network_packet_schema` to inspect pinned elpis packet layouts, fields, enums, provenance and aliases. `network_capture_status` also reports the schema catalog.
- Adds read-only `network_capture_parse`, automatically selecting by the capture's pinned opcode name, FFXIVOpcodes alias and direction, skipping send 32 / receive 16-byte headers. Supports nested objects, fixed arrays, integers, floats, UTF-8, bytes, bitsets, enums and fixed-point display values, paged fields, explicit missing/truncated states and same-direction caller-selected schemas. Existing caller-declared decoding remains available.
- Ships static metadata from elpis-network / elpis-struct 0.1.0: 177 packet mappings and 218 reachable structures. 170 have direction/name catalog metadata (157 receive, 13 send); seven Fellowship schemas lack it and remain query-only. The importer checks pinned npm SHA-512 and catalog SHA-256. Runtime executes no JavaScript, needs no Node and fetches no remote schemas. GPL / AGPL and FFXIVClientStructs MIT notices ship in the ZIP; the generator and JSON are published with source.
- Validation: Debug / Release builds completed with zero warnings/errors; 333 network checks, 207 Release plugin-load checks and 59 protocol checks passed. Regenerating the pinned snapshot produced the same SHA-256. The live game's MVID matched the tested DLL, with all catalog pages totaling 159 tools. A passive 10-second sample captured 80 messages (5 send, 75 receive); 11 schema types matched, 1431 available fields agreed with independent Python decoding and 3091 live assertions passed. No gameplay input or packet injection was used; both observation hooks were disabled afterward.
- Actual limitations: 65 sampled messages completed layout reads. Four ActionRequest payloads were 32 bytes versus the schema's 40, explicitly returning `short_payload` without zero-padding missing tails. Nine messages lacked opcode names and two lacked schemas. Imported counts do not certify complete current-CN coverage; length/name matches do not certify semantics or patch compatibility. Conditional display/entry validity rules are metadata only; EXD names are not automatically resolved. Capture remains restricted to the inspected CN in-process zone IPC backend. High load, every packet type and other regions have not been comprehensively validated. This is not a complete protocol, TCP/PCAP capture or server-delivery confirmation.

Details: [packet schemas](https://github.com/NiGuangOwO/DalamudMCP/blob/v1.0.0.37/docs/packet-schemas.md); [live verification](https://github.com/NiGuangOwO/DalamudMCP/blob/v1.0.0.37/research/network-schemas-2026-11-01/live-verification.json).
